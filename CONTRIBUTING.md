# Contributing

Describe the problem and expected behavior before proposing a change. For bugs include the commit/build, game version, OS/GPU/driver, launcher settings, checkpoint and reproduction steps. Indicate whether recording software is running. Share only relevant log excerpts with personal paths removed.

Do not upload game files, ISOs, DLC, generated game code or personal saves. Keep changes focused and describe validation honestly. Project-authored contributions are submitted under GPL-3.0-only; see LICENSE and COPYRIGHT.md. Preserve upstream notices when modifying third-party-derived code.
